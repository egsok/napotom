  <name>Task 2: Fix yt-dlp version detection (BUG-02)</name>
  <files>src/core/updater.py, src/ui/settings_dialog.py</files>
  <action>
The current version detection can fail silently in PyInstaller-bundled apps. Implement defensive multi-strategy version detection.

**In src/core/updater.py - UpdateChecker.run():**
Replace the direct import with defensive pattern:

```python
@pyqtSlot()
def run(self):
    """Check for updates."""
    try:
        current = self._get_current_version()
        
        # Check PyPI for latest version
        import urllib.request
        import json

        url = "https://pypi.org/pypi/yt-dlp/json"
        with urllib.request.urlopen(url, timeout=10) as response:
            data = json.loads(response.read())
            latest = data['info']['version']

        self.signals.version_checked.emit(current, latest)

    except Exception as e:
        self.signals.version_checked.emit("error", str(e))

def _get_current_version(self) -> str:
    """Get installed yt-dlp version with fallback strategies."""
    # Strategy 1: Direct attribute access (fastest)
    try:
        import yt_dlp
        version = getattr(yt_dlp, 'version', None)
        if version:
            v = getattr(version, '__version__', None)
            if v:
                return v
    except Exception:
        pass
    
    # Strategy 2: Direct module import
    try:
        from yt_dlp import version
        return version.__version__
    except Exception:
        pass
    
    return "Unknown"
```
