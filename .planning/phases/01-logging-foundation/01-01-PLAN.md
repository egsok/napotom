<task type="auto">
  <name>Task 1: Create logger module</name>
  <files>src/utils/logger.py</files>
  <action>
Create `src/utils/logger.py` with:

1. Import `logging`, `RotatingFileHandler` from `logging.handlers`, `Path`
2. Import `get_app_data_dir` from `utils.config` (relative import: `from .config import get_app_data_dir`)
3. Create `_log_file_path` module-level variable to store the path

4. Create `get_log_file_path() -> Path | None` function:
   - Returns `_log_file_path` (so other modules can display it)

5. Create `setup_logging(level: int = logging.DEBUG) -> Path` function:
   - Create logs directory: `log_dir = get_app_data_dir() / 'logs'`
   - Create directory: `log_dir.mkdir(parents=True, exist_ok=True)`
   - Set log file path: `log_file = log_dir / 'app.log'`
   - Store in module variable: `global _log_file_path; _log_file_path = log_file`
   - Create formatter with: `'%(asctime)s - %(name)s - %(levelname)s - %(message)s'`
   - Create `RotatingFileHandler` with:
     - `log_file` as path
     - `maxBytes=5 * 1024 * 1024` (5 MB)
     - `backupCount=3`
     - `encoding='utf-8'`
   - Set handler level to `logging.DEBUG`
   - Set handler formatter
   - Get root logger: `logging.getLogger()`
   - Set root logger level
   - Add handler to root logger
   - Return `log_file` path

IMPORTANT: Use %-style formatting in all docstrings and comments (not f-strings).
  </action>

  </verify>

  </done>
