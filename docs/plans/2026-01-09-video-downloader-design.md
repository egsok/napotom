# Video Downloader 2 — Design Document

**Дата:** 2026-01-09
**Статус:** Утверждён

## Обзор

Desktop-приложение для скачивания видео с YouTube, VK, Vimeo, Wistia и X (Twitter). Построено на Python + PyQt6 + yt-dlp.

## Технологический стек

- **Python 3.11+** — основной язык
- **PyQt6** — GUI фреймворк
- **yt-dlp** — движок скачивания (поддерживает 1000+ сайтов)
- **ffmpeg** — мерж видео/аудио, конвертация
- **PyInstaller** — сборка в .exe

## Ключевые решения

### Пресеты качества

| Пресет | yt-dlp format string |
|--------|---------------------|
| Лучшее | `bestvideo+bestaudio/best` |
| 1080p | `bestvideo[height<=1080]+bestaudio/best[height<=1080]` |
| 720p | `bestvideo[height<=720]+bestaudio/best[height<=720]` |
| Аудио | `bestaudio/best` + extract-audio |

### Очередь скачиваний

- Последовательная загрузка (одно видео за раз)
- Состояния: `pending`, `downloading`, `completed`, `failed`, `cancelled`
- Можно удалить/отменить элементы

### Сохранение файлов

- Папка по умолчанию + возможность выбрать другую для конкретного видео
- Настройки в `%APPDATA%/VideoDownloader2/config.json`

### Уведомления

- Системные Windows toast-уведомления
- Звук при завершении
- Оба отключаются в настройках

### Автообновление yt-dlp

- Проверка при запуске приложения
- Диалог "Доступно обновление. Установить?"
- Обновление через pip в фоне

## Конфиг

```json
{
  "download_path": "D:\\Videos",
  "default_quality": "best",
  "notifications_enabled": true,
  "sound_enabled": true,
  "check_updates": true
}
```

## Сборка

```bash
pyinstaller --onefile --windowed --icon=icon.ico --name="VideoDownloader2" src/main.py
```

Результат: `VideoDownloader2.exe` (~50-80 MB), включает yt-dlp и ffmpeg.
